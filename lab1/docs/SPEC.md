# ЛР №1 «Основы 3D-графики» — спецификация (вариант 8: цилиндр)

Источники: `docs/CG Lab #1.pdf`, лекции `docs/CG Lecture #1–3`, указания преподавателя в `docs/msgs.txt`.
План реализации с чекпоинтами: [PLAN.md](PLAN.md).

## 1. Требования

### Базовые (оценка 3)
- **R1.** Vulkan + GLFW + ImGui на стартовом коде. Код лабы — в `application.cpp`,
  переиспользуемые абстракции — в `graphics.hpp/.cpp` (указание преподавателя).
- **R2.** 3D-цилиндр, ~50 вершин в каждом основании.
- **R3.** Отрисовка в реальном времени с корректной проекцией на 2D.
- **R4.** Проекция и трансформации меняются динамически, есть взаимодействие с пользователем.
- **R5.** Все объекты Vulkan уничтожаются (`vkCreate*` ↔ `vkDestroy*`), валидация без сообщений.

### Дополнительные (1–5 → оценка 4, все 6 → оценка 5)
- **E1.** Переключение ортографической и перспективной проекции в интерфейсе.
- **E2.** Интерфейс для позиции, поворота и масштаба фигуры.
- **E3.** Движение и вращение по сложной траектории; пауза/воспроизведение, скорость
  и параметры траектории (радиус и др.).
- **E4.** Цвет фигуры через `ImGui::ColorEdit`.
- **E5.** Процедурный цвет вершин по их позиции в локальной системе координат;
  цвет из интерфейса **умножается** на цвет вершин.
- **E6.** Несколько объектов на сцене, используя больше одного `VkDescriptorSet`.

## 2. Конвенции (из лекции 1)

| Что | Значение |
|---|---|
| Оси | правая система: x вправо, **y вниз**, z вглубь экрана; камера смотрит вдоль +z |
| Clip-пространство Vulkan | x, y ∈ [−1, 1], z ∈ [0, 1] |
| Векторы / точки | однородные координаты: точка `w = 1`, вектор `w = 0`; вектор-столбец, `p' = M·p` |
| Хранение матриц | по столбцам (column-major, `glm::mat4`) — как `mat4` в GLSL std140, `memcpy` без транспонирования |
| Лицевая грань | обход по часовой стрелке на экране (`VK_FRONT_FACE_CLOCKWISE`), `cullMode = BACK` |
| Буфер глубины | `depthCompareOp = LESS`, очистка значением 1.0 |

Матрицы проекций — ровно как на слайдах лекции 1:

```
Orthographic(l, r, b, t, n, f):            Perspective(θ, aspect, n, f):
| 2/(r−l)  0        0        −(r+l)/(r−l) | | 1/(aspect·tan θ/2)  0            0          0         |
| 0        2/(b−t)  0        −(b+t)/(b−t) | | 0                   1/tan θ/2    0          0         |
| 0        0        1/(f−n)  −n/(f−n)     | | 0                   0            f/(f−n)   −f·n/(f−n) |
| 0        0        0        1            | | 0                   0            1          0         |
```

При y вниз «верх» экрана — это `t < 0`, «низ» — `b > 0`.

## 3. Решения

| Тема | Решение | Почему |
|---|---|---|
| Математика | GLM (разрешено преподавателем): `glm::perspectiveLH_ZO`, `glm::orthoLH_ZO`, `glm::translate/rotate/scale`, `glm::convertSRGBToLinear` | `LH_ZO` численно совпадает с матрицами лекции 1 (камера смотрит вдоль +z, глубина [0, 1]) — это проверяют юнит-тесты; обычный `glm::perspective` — вариант OpenGL |
| Цилиндр | ось вдоль Y, центр в начале координат, R = 0.5, H = 1, N = 50 сегментов: 2·50 вершин на ободах + 2 центра = 102 вершины, 200 треугольников | «~50 вершин в основаниях» |
| Процедурный цвет | `color = (p − bbox_min) / (bbox_max − bbox_min)` → r←x, g←y, b←z | зависит от локальной позиции (E5) |
| Цвет из UI | ColorEdit отдаёт sRGB → переводим в линейное пространство перед загрузкой | swapchain `B8G8R8A8_SRGB` сам кодирует в sRGB, так что на экране будет ровно выбранный цвет |
| Дескрипторы | set 0 = `GlobalUniforms { mat4 view_projection }` (один на кадр); set 1 = `ObjectUniforms { mat4 model; vec4 color; vec4 params }` (по одному на объект) | E6 + разделение по частоте обновления |
| Объекты | до 8 штук, буферы и наборы дескрипторов создаются заранее в `initialize` | нет пересоздания ресурсов во время кадра |
| Запись uniform-данных | в `update` только вычисления; `memcpy` в буферы — в `render`, после ожидания fence в `prepare()` | `update` вызывается до ожидания fence → запись в буфер, который ещё читает GPU, — гонка |
| Камера | орбитальная: `view = T(0, 0, D) · Rx(pitch) · Ry(yaw)` | наглядный 3D-вид (видна крышка), взаимодействие с пользователем |
| Траектория (E3) | эпициклоида («цветок») в плоскости XZ + вертикальное колебание, вращение вокруг своей оси | «сложная траектория» с параметрами: радиусы, число лепестков, амплитуда, скорость вращения |
| Анимация | время анимации накапливается `t += dt · speed` только в режиме «Play» | пауза и смена скорости без скачков |
| Масштаб | ограничен снизу 0.1 | отрицательный масштаб зеркалит объект и меняет обход треугольников |
| Слоты объектов | новый объект получает наименьший свободный слот: своё место, цвет палитры, фазу на траектории | после удаления объекта из середины новый не совпадает с существующим |

## 4. Интерфейс (ImGui: окно «Scene» слева, «Objects» справа)
- **Проекция:** радиокнопки Perspective / Orthographic; угол обзора FOV (перспектива),
  высота видимой области (орто).
- **Камера:** расстояние, рыскание (yaw), тангаж (pitch).
- **Анимация:** включение движения, Play/Pause, скорость, сброс времени, параметры траектории.
- **Объекты:** список, добавить/удалить (1…8), выбор текущего.
- **Текущий объект:** позиция, поворот (градусы), масштаб; цвет (ColorEdit3); флажок «цвета вершин».
- **Мышь:** перетаскивание вращает камеру, колесо приближает.
- **Статистика:** FPS, число вершин и треугольников.

## 5. Тестовые хуки (переменные окружения)
Нужны только для воспроизводимых автотестов; значения по умолчанию — обычный режим.

| Переменная | Значения | Действие |
|---|---|---|
| `LAB1_PROJECTION` | `perspective` \| `orthographic` | стартовая проекция |
| `LAB1_ANIMATE` | `0` \| `1` | движение по траектории выключено / включено и запущено |
| `LAB1_OBJECTS` | `1…8` | стартовое число объектов |
| `LAB1_COLOR` | `r,g,b` (sRGB, 0…1) | цвет всех объектов |
| `LAB1_VERTEX_COLORS` | `0` \| `1` | умножать ли на цвета вершин |
| `LAB1_CAMERA_PITCH` | градусы | стартовый тангаж камеры |
| `LAB1_HIDE_UI` | `0` \| `1` | не рисовать окна ImGui (чтобы не перекрывали кадр) |

## 6. Критерии приёмки

### Автоматические
| # | Критерий | Как проверяется |
|---|---|---|
| A1 | сборка Debug и Release без предупреждений (`-Wall -Wextra`) | лог сборки |
| A2 | все юнит-тесты проходят | `lab1-tests.exe` (doctest) |
| A3 | раскладка uniform-блоков в шейдере совпадает с C++-структурами | `spirv-cross --reflect` + `static_assert(offsetof…)` |
| A4 | ноль сообщений валидации (включая синхронизацию), выход с кодом 0, нет утечек объектов | интеграционный прогон с логом валидации |
| A5 | ширина силуэта цилиндра в центральной строке кадра совпадает с аналитической (±2 px) для обеих проекций | кадр со слоя `VK_LAYER_LUNARG_screenshot` |
| A6 | однотонный цвет объекта на экране равен выбранному в UI (±3 из 255) | тот же кадр |
| A7 | с цветами вершин объект неоднородный, центральный пиксель равен предсказанному процедурному цвету | тот же кадр |
| A8 | N объектов → N областей своего цвета в ожидаемых местах | тот же кадр |
| A9 | на паузе кадры 30 и 90 одинаковые, при анимации — разные | два кадра |
| A10 | ресайз, сворачивание и разворачивание без падений и ошибок валидации | стресс-скрипт |

### Ручные (чек-лист в PLAN.md, этап 9)
Все элементы интерфейса реально меняют сцену; при изменении размера окна пропорции не искажаются;
в ортографической проекции дальняя и ближняя крышки одного размера, в перспективе — нет.
