# Лабораторная работа №4. Наложение теней

Сцена из ЛР №3 содержит три текстурированных цилиндра. В ЛР №4 они отбрасывают тени на деревянный пол. Карты строятся для солнца и первого прожектора.

## Запуск

Из корня `lab4` в PowerShell:

```powershell
.\build-debug\vulkan-starter-app.exe
```

В VS Code можно открыть папку `lab4` и нажать F5. В панели **Scene → Lighting** параметр **Sun coverage (side)** задаёт сторону квадратной области солнечной проекции, а **Depth bias** меняет смещение при записи в карты глубины. Чтобы увидеть вклад прожектора отдельно, установите интенсивность солнца и точечного источника в ноль.
