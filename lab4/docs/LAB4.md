# ЛР №4. Наложение теней

Основа — сцена, материалы, динамический буфер объектов и интерфейс ЛР №3. Условие и лекции 7–8 находятся в `docs/materials`.

| Пункт задания | Реализация |
|---|---|
| Карта глубины каждый кадр | До вывода сцены функция `renderShadowMap` записывает глубину через `vkCmdBeginRendering`. Между записью глубины и чтением из фрагментного шейдера установлен барьер. |
| Конвейер для глубины | `graphics.cpp` задаёт формат через `VkPipelineRenderingCreateInfo`. Единственная стадия использует `shadow.vert`. |
| Направленный свет | `uploadUniforms` строит матрицу ортографической проекции и LookAt вдоль лучей солнца. Положение камеры задаёт центр области охвата. |
| Сравнение глубины | `createShadowMaps` создаёт отдельный сэмплер с `compareEnable` и `VK_COMPARE_OP_LESS`. Шейдер `object.frag` использует `sampler2DShadow`. Координаты вне объёма карты считаются освещёнными. |
| Пол и интерфейс | Пол состоит из двух треугольников и использует материал Wood из ЛР №3. В разделе Lighting регулируются сторона области солнечной проекции и depth bias. |
| Дополнительное задание | Первый прожектор использует отдельную карту, перспективную проекцию по внешнему углу конуса и ту же геометрию. Остальные прожекторы используют освещение ЛР №3. |

В интеграционном сценарии `floor_shadows` камера смотрит сверху на цилиндр. Один и тот же кадр снимается при фоновом освещении, с солнцем и с прожектором. Для каждого источника проверяются две точки на полу. За цилиндром цвет совпадает с фоновым, а на освещённом участке отличается. Сценарий `uniform_layout` сверяет раскладку uniform-блоков с отражением скомпилированных шейдеров.
