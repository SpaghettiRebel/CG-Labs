## 2. Решения

| Тема | Решение | Почему |
|---|---|---|
| Камера | позиция и поворот: yaw — вокруг вертикали (> 0 вправо), pitch — наклон (> 0 вниз). Матрица камеры `C = T(position)·Ry(yaw)·Rx(−pitch)`, матрица вида `V = C⁻¹ = R⁻¹·T⁻¹ = Rᵀ·T(−position)` | лекция 4: камера — объект с позицией и поворотом, вид — обратная матрица; обратная к повороту — транспонированная, к переносу — перенос назад, без обращения 4×4 |
| Орбитальная камера мышью из ЛР №1 | удалена | камера теперь задаётся позицией и поворотом через интерфейс |
| Направления источников | те же yaw и pitch, что у камеры (`scene::forwardDirection`) | направление никогда не бывает нулевым вектором, нормировать нечего |
| Нормали | у крышек свои вершины с нормалью ±y, у боковой поверхности — радиальная нормаль: 4·50 + 2 = 202 вершины | в общей вершине обода нельзя хранить две нормали |
| Нормали в шейдере | `transpose(inverse(mat3(model)))` | при неравномерном масштабе (ЛР №1) обычная матрица модели наклоняет нормали |
| Модель освещения | для каждого источника `E·(ρd·(n·l) + ρs·max(n·h, 0)^α)` при `n·l > 0`, иначе 0; итог `ambient·ρd + Σ` | слайд 23 лекции 4. На слайде 18 у диффузной части лишний множитель `(n·l)` — опечатка |
| Затухание | `E = цвет·интенсивность / D²` для точечных и прожекторов | слайд 27 |
| Мягкий край прожектора | `clamp((cos θ − cos θout) / (cos θin − cos θout), 0, 1)`, углы отсчитываются от оси; внешний угол меньше внутреннего считается равным ему | линейный переход между углами, при равных углах — жёсткий край |
| Цвета | в интерфейсе sRGB, в шейдер — линейные, умноженные на интенсивность (как в ЛР №1) | swapchain `B8G8R8A8_SRGB` кодирует обратно |
| Дескрипторы | set 0: binding 0 `SceneUniforms` (UBO), 1 `PointLights` (SSBO), 2 `SpotLights` (SSBO); set 1: binding 0 `ObjectUniforms` | раскладка со слайдов 31–32 |
| Размер массивов | в шейдере массивы без размера, число источников — в `SceneUniforms`; storage-буферы на CPU — на 16 источников каждого типа, кнопка Add отключается при заполнении | задание: не задавать максимум в шейдере |
| Выравнивание | каждый `vec3` в паре с 4-байтовым полем (счётчик, косинус) или явным `padding` в C++ | в std140/std430 `vec3` выравнивается на 16 байт; проверяют `static_assert` и рефлексия SPIR-V |
| Визуализация | отдельные конвейеры без освещения и без наборов дескрипторов: треугольники для кубов, линии для конусов; матрица MVP и цвет — push constants | число фигур меняется вместе с числом источников, отдельный буфер на фигуру не нужен |
| Значения по умолчанию | рассеянный 0.05, направленный 0.6, один точечный и один прожектор; прожектор направлен на переднюю сторону цилиндра | сцена видна сразу; интеграционный тест проверяет все три зоны прожектора на одной линии |

## 3. Проверка

**Юнит-тесты** (`tests/unit/`): нормали (единичные, наружу, согласованы с обходом треугольников), замкнутость сеток
цилиндра и куба, конус из линий, обход треугольников на экране для камер с разных сторон; поворот по yaw/pitch,
матрица вида = `inverse(T·R)`, камера вокруг начала координат; перевод материала и источников в данные шейдера (sRGB →
линейный, интенсивность, косинусы, ограничение числа источников), матрица конуса прожектора; `LAB1_LIGHTS`.

**Интеграционные тесты** (`tests/integration/run.ps1`): кадр снимается слоем `VK_LAYER_LUNARG_screenshot`, цвет пикселя
сравнивается с цветом, посчитанным в тесте по формуле Блинна–Фонга (без C++-кода приложения). Проверяется передняя линия
цилиндра `x = 0` при виде сбоку: там известны точка и нормаль `(0, 0, −1)`.
- `uniform_layout`: смещения полей `SceneUniforms`, `ObjectUniforms`, `MarkerConstants`, шаг и поля элементов `PointLights`, `SpotLights` в SPIR-V;
- `ambient_only`: без источников цвет = рассеянный свет × альбедо;
- `directional_light`: передняя линия; сторона, отвёрнутая от света, — только рассеянный свет;
- `point_light`: передняя линия, точки на разных расстояниях от источника (1/D²);
- `spot_light`: передняя линия проходит через полный свет, мягкий край и тень прожектора;
- `light_markers`: куб источника имеет ровно цвет источника, есть белые линии конуса; при скрытии — фон;
- `vertex_colors`: центр верхней крышки = цвет вершины × альбедо, освещённый направленным источником;
- тесты ЛР №1: проекции, ресайз, анимация, несколько объектов, ошибки опций, окно (валидация и утечки — в каждом запуске).

**Мутационная проверка:** в код по одной вносились ошибки (вид без обращения поворота, неверные нормали, 1/D вместо
1/D², жёсткий край прожектора, Фонг вместо Блинна–Фонга, нет блика, нет рассеянного света, неверное смещение атрибута
нормали и др.) — каждую ловит хотя бы один тест.

Тестовые переменные окружения ЛР №1 сохранены; добавлены `LAB1_LIGHTS` (`none` или список из `directional`, `point`,
`spot` — какие источники по умолчанию оставить) и `LAB1_SHOW_LIGHTS` (`0` | `1`). `LAB1_CAMERA_PITCH` ставит камеру
на расстоянии 3 от начала координат с заданным наклоном, `LAB1_COLOR` задаёт альбедо.
